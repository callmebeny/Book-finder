# Book Finder

Type a book name in the form and press **Search**. The page shows 10 book titles.

## Files

```
project/
├── index.html   - the page and the form
├── style.css    - the design
├── script.js    - one fetch request to the API
└── readme.md    - this file
```

## How to use

Open `index.html` in your browser, type a book name and press **Search**.

## API

Free [Open Library API](https://openlibrary.org/developers/api), no key needed:

`https://openlibrary.org/search.json?q=harry+potter`
